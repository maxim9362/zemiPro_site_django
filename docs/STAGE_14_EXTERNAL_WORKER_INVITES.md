# Stage 14.11 — приглашение внешнего мастера

## Поток

Авторизованный пользователь создаёт ссылку, действующую семь дней, и сам
копирует её либо открывает фиксированный Facebook/Messenger sharer. ZemiPro не
просит данные адресата, не читает адресную книгу и не отправляет сообщение.
Получатель самостоятельно открывает ссылку и проходит штатную регистрацию.

## Минимизация и безопасность

- raw token генерируется `secrets`, отображается только в ответе создания и не
  хранится; в PostgreSQL остаётся HMAC-SHA256 digest;
- ссылка не даёт прав, не подтверждает email и не создаёт WorkerProfile;
- expiry — 7 дней, successful registration учитывается не более одного раза;
- новый User ID не связывается с пригласившим: сохраняются только aggregate
  `opened_count`, `claimed_count=0/1` и техническое время claim;
- inviter/token/expiry/creation и завершённый claim неизменяемы DB trigger;
- ссылка отделена от Stage05 приглашения уже зарегистрированного мастера к
  конкретной заявке.

`ZEMIPRO_EXTERNAL_WORKER_INVITES_ENABLED=False` остаётся hard-off. Реальные
сообщения, пользователи, согласия или conversion claims не создавались.
