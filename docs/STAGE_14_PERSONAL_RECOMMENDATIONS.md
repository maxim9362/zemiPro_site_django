# Stage 14.8 — личные рекомендации

Личная рекомендация описывает добровольно подтверждённый опыт автора вне
ZemiPro. Это отдельный тип knowledge-контента: он не связан с заказом, не
является проверенным отзывом и никогда не меняет `Rating` мастера.

Публикация требует активного реального автора, опубликованного мастера Ашдода,
явного подтверждения личного опыта и независимой ручной модерации. Запрещены
саморекомендация, повтор author/worker, контакты, ссылки и HTML. Публичный текст
берётся только из одобренного снимка; история и исходные данные жалоб защищены
PostgreSQL triggers.

Флаг `ZEMIPRO_PERSONAL_RECOMMENDATIONS_ENABLED=False` остаётся выключенным и не
читается из окружения. CI на синтетических данных не заменяет реальные согласия
и отдельное разрешение владельца на публичную активацию.
