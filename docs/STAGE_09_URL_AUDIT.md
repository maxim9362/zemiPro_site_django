# Stage 09.1 — проверка опубликованных URL

**Дата проверки:** 2026-11-15  
**Область:** только публичные URL `zemipro.co.il`; production, DNS, Cloudflare,
VPS и рабочая БД не изменялись.

## Результат

Исходный реестр содержит **21 уникальный URL**: главную, два региональных
раздела, три раздела/категории и пятнадцать страниц услуг. Это подтверждённый
выборочный реестр, но не доказательство полного sitemap или индекса Google.

Из Codex Cloud выполнены две одинаковые щадящие попытки HTTPS GET главной
страницы с `connect-timeout=8`, `max-time=20` и идентифицируемым User-Agent:
обычная и разрешённая внешняя. Обе остановлены инфраструктурным CONNECT-прокси
до соединения с сайтом:

```text
curl: (56) CONNECT tunnel failed, response 403
http_status=000
```

`000` не является HTTP-статусом сайта. Поэтому HTTP-коды, redirect chain,
canonical, `robots.txt` и sitemap остаются `UNKNOWN`. Зафиксированные ранее
`PAGE_OPENED`/`SEARCH_RESULT` не повышены до текущей HTTP-проверки.

## Решения-кандидаты

| Группа | Количество | Кандидат | Причина |
|---|---:|---|---|
| `/` | 1 | `KEEP` | Django сохраняет корневую главную; окончательное подтверждение — на staging/cutover. |
| `/master/lachish/`, `/master/center/` | 2 | `REVIEW` | Старые регионы не равны разрешённой географии Ашдода. Редирект на Ашдод или главную был бы нерелевантным. |
| Старые разделы/категории | 3 | `REVIEW` | Нужны HTTP/GSC и точное соответствие актуальному Django-каталогу. |
| Старые услуги | 15 | `REVIEW` | Нужны HTTP/GSC, подтверждённая новая услуга и реально полезная целевая страница. |

Ни один `301`, `404` или `410` не активируется только по предположению. Механизм
Stage 09.5 будет fail-closed: точная запись, редакционное одобрение, существующая
локализованная цель и отдельный feature flag.

## Что требуется от владельца / GSC

Для закрытия внешнего гейта нужен экспорт Google Search Console за последние
16 месяцев (CSV/Google Sheets) без пользовательских данных:

1. Performance → Pages: URL, clicks, impressions, CTR, position, date range.
2. Page indexing: submitted/indexed/not indexed и причина.
3. Sitemaps: адрес, last read, discovered pages и errors.
4. URL Inspection для 21 строк реестра: Google-selected canonical и last crawl.
5. При наличии — список внешних ссылок по target page.

Также требуется запуск `curl`/браузерной проверки из сети без блокирующего
CONNECT-прокси. До этого гейт 00.4 и полнота 09.1 имеют статус
`EXTERNAL_EVIDENCE_PENDING`, а не `DONE`.

## Проверяемые допущения

- Неизвестных массовых шаблонов нельзя исключить без sitemap/GSC и доступного
  crawl; это явно остаётся внешним ограничением.
- В реестр не добавлялись сгенерированные догадки.
- Старый Flask/PSEO-код, тексты, SQLite и AI-генераторы не использовались.
- Пилот остаётся только в Ашдоде; `lachish` и `center` не становятся новой
  публичной географией.
