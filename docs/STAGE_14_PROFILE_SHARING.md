# Stage 14.9 — передача публичной ссылки

Функция не интегрируется с аккаунтом Facebook. Пользователь сам нажимает
Facebook share либо копирует URL уже существующей публичной карточки мастера.
Нет Meta API, Facebook Login, токенов, списка друзей, чтения профиля,
автоматических публикаций или импорта контактов.

Сервер заново применяет действующий public-worker predicate и разрешает только
фиксированный домен/путь Facebook sharer. Произвольный destination не
принимается. Для копирования используется browser Clipboard API; без JavaScript
показывается readonly публичная ссылка.

Флаг `ZEMIPRO_PROFILE_SHARING_ENABLED=False` остаётся закрытым до отдельной
приёмки и выпуска. CI не выполняет реальных действий во внешнем Facebook.
