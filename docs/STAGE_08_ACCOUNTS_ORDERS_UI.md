## Границы реализации

Только фронтенд-слой существующего Django: Templates, CSS, небольшой vanilla JS.
Использованы существующие модели, сервисы, POST формы, CSRF, статусы, права доступа,
ценовые и географические ограничения. Без React, SPA, новых зависимостей, схемных миграций,
изменений платежей, фоновых сервисов и production. Пилот — только Ашдод.

\`order_wizard_edit_view\` для **атомарного сохранения валидного шага перед возвратом**.

подтверждения шага 8. Никакого отдельного API и обхода прав.

## Гарантии при вводе и переходе между шагами

- Поля wizard заполняются из PostgreSQL-черновика. При ошибке Django
  повторно отображает **bound form**, сохраняя текущие введённые значения,
  а сервер не принимает недействительную запись.
- Для **шагов 2–7** кнопка «Сохранить и назад» отправляет защищённый POST
  \`action=back\`. Только валидный шаг сохраняется в PostgreSQL через прежний
  сервис, затем выполняется переход на \`?step=<previous>\`. Невалидный остаётся
  на экране с ошибками и полями. Контроль владельца, статуса draft,
  последовательности шагов и квот неизменён.
- Основная кнопка submit расположена первой в DOM: клавиша Enter
  выполняет привычное «Сохранить и продолжить», а не случайный возврат.
- **Шаг 8** не имеет save-back операции, потому что согласие на публикацию
  нельзя молча сохранять. Возврат к шагу 7 — GET; JS предупреждает о
  несохранённом согласии. При отключённом JS показаны серверные формы.
- На шаге 1 без JS пользователь может отправить выбранную категорию,
  получить от сервера список услуг после ошибки обязательного выбора,
  затем выбрать услугу; механизм проверки самой услуги не обходится.
- Выбор видимости фотографий и чекбокс согласия сохраняются при повторном
  отображении ошибочного POST. **Сам файл браузер не может автоматически
  восстановить** после ошибочной отправки по соображениям безопасности;
  интерфейс прямо сообщает о необходимости повторного выбора.
- JS \`static/js/wizard-navigation.js\` не сохраняет личные данные
  в localStorage/sessionStorage, не отправляет их третьим лицам и не заменяет
  серверный источник истины.
