## Реализованные страницы

- \`pages/home.html\`: двухмаршрутный hero («Найти специалиста» / «Создать заявку»), акцент **пилот только Ашдод**, правдивый текст: без посредников и платежей, без публичного точного адреса/телефона. Сохранён базовый переведённый заголовок Stage02 для обратной совместимости.
- \`pages/categories.html\` и \`section_detail.html\`: группировка существующих активных категорий по реальным разделам; одна карточка \`components/service_card.html\`; пустые состояния; ссылки только на существующие локализованные URL.
- \`pages/service_detail.html\`: карточка реальной услуги и два пути — точный поиск \`?service=<pk>\` среди мастеров, указавших её, и мастер заявки. Без заявления, будто платформа удостоверяет качество.
- \`pages/cities.html\` / \`city_detail.html\`: публичная география остаётся Ashdod-only на сервере; выбор категории GET с подписью, кнопкой применения и без JavaScript; карточки, пагинация и пустые результаты.
- \`pages/category_detail.html\`: услуги внутри категории, фильтр по публичным городам через GET с label и кнопкой, сохранение текущего выбора и пагинации, каталог специалистов.
- \`pages/worker_directory.html\`: три основных поля (\`q\`, \`category\`, \`service\`), сортировка и раскрываемые дополнительные серверные фильтры. Нет JS-зависимости: \`<details>\` — нативный контрол. Сохранены безопасная \`pagination_query\`, серверные invalid-form/PII restrictions и честное ранжирование. В \`components/worker_card.html\` добавлена только безопасная \`public_description\`.
- \`pages/worker_public_profile.html\`: адаптивная карточка, зоны/категории/услуги, реальные оценки, безопасные примеры работ, отзывы/ответы, приглашение в существующий заказ или создание заявки, избранное и жалоба с прежними server-side разрешениями.
- Общий \`pages/public_base.html\` загружает только на публичных страницах \`static/css/public-pages.css\`, поверх сохранённой Stage08.2 дизайн-системы. Без новых фреймворков, шрифтов, API или JS для поиска.
- \`components/worker_summary_card.html\`: общая публичная карточка для страниц категории и города; только \`public_display_name\`, \`public_description\`, действительные агрегированные оценки, разрешённые данные.
- RU/EN/HE в новых уникальных строках локализованы явными шаблонными ветками, без изменения скомпилированных каталожных .mo, RTL и общая навигация из Stage08.2 сохранены. Суммы/числа изолированы bdi.
