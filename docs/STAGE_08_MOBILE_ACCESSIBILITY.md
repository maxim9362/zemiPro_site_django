## Выполненные изменения

1. **Общие поля и ошибки.** `apps/accounts/templatetags/a11y_widgets.py` — исключительно presentation-level `ui_widget`: сохраняет нативные имена/значения, серверную валидацию, существующий `aria-describedby`, добавляет ID подсказки/ошибок и `aria-invalid=true` только при реальной ошибке. `templates/components/form_field.html` задаёт связанные `<label>`, текст помощи, `role=alert` и ссылки для скринридера. Данные не сериализуются в JS и не отправляются за пределы Django.
2. **Мастер заказа.** `pages/order_wizard.html`: заголовок текущего шага с ID, обозначенный `progress`, новые ошибки динамических вопросов и обычных полей с `aria-describedby`, `aria-invalid`, доступные подсказки. Сохранены 8 шагов, исходные CSRF, POST `next`/`back`/`publish`, ограничения публикации и photo-consent. Содержимое поля сохраняет Django BoundField, без клиентского обхода валидации.
3. **Навигация.** `templates/base.html`, `static/js/navigation.js`: локализованное RU/EN/HE название кнопки меню при открытии/закрытии, синхронизация с `aria-expanded`, Escape закрывает и возвращает фокус. Без JS ссылки меню остаются видимыми; переключение языка имеет `<noscript>` кнопку.
4. **Контраст и рефлоу.** `design-system.css`, `app-pages.css`, `public-pages.css`, `communication.css`: явно различимые фокусные контуры на тёмных и светлых поверхностях, значения токенов контраста, обработка 200% размера текста, размеченные controls, logical `inline`-свойства вместо LTR-зависимых отступов, числовые/e-mail/телефонные значения изолированы в RTL, предотвращение широких селектов, таблиц и кнопок на 320px, scroll-offset для якорей под sticky-header. `prefers-reduced-motion` и повышенный контраст не отменены.
5. **Переводы.** На общих экранах сохраняются `lang=ru/en/he`, `dir=rtl` на Hebrew, локализованные подписи меню и трёхъязычные уникальные тексты модерации/уведомлений. Нет расширения каталога географии или новых SMS-механизмов.
6. **Изолированная проверка.** `scripts/stage08_mobile_a11y_smoke.py` добавляет реальный Chromium viewport/keyboard/no-JS smoke в test-only PostgreSQL 17; `.github/workflows/django-ci.yml` запускает его автоматически и сохраняет временные скриншоты (7 дней). Скрипт проверяет только `DJANGO_ENV=test` и `ZEMIPRO_TEST_ASHDOD_ONLY=1` и не обращается к production.
