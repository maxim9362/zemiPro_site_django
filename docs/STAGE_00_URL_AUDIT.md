# ZemiPro — этап 00.4: первичная инвентаризация публичных URL

**Дата:** 2026-11-11
**Статус:** `DEFERRED / RETURN_BEFORE_STAGE_08`
**Продуктовое решение:** `docs/DECISIONS/ADR-0002-REBUILD-WITH-URL-ONLY.md` — старые PSEO Flask/SQLite/тексты не переносим. Для будущего Django-сайта сохраняем только те URL, у которых после отдельной проверки есть ценность.

## Результат

Создан `docs/SEO_URL_INVENTORY.csv` из **21 уникального URL**, взятого из публичных результатов:
- **11** страниц, для которых веб-инструмент вернул содержимое HTML после открытия страницы/навигации по сайту;
- **10** страниц, обнаруженных как публичные поисковые результаты; текущая доступность этих десяти страниц не подтверждена отдельной HTTP-проверкой.
- Типы: главная, региональные хабы, категорийный хаб, регионально-категорийные хабы, карточки услуг/профессий.
- Это **выборочный**, а не исчерпывающий список. Он не равен sitemap, индексу Google или полному количеству опубликованных страниц.

`http_status`, `canonical`, `google_index_status`, `gsc_clicks`, `gsc_impressions`, `target_new_url` оставлены `UNVERIFIED`/`UNKNOWN` или пустыми. Нельзя делать вывод, что URL возвращают именно HTTP 200 на дату аудита, что они индексированы Google, что они генерируют трафик или заслуживают 301.

## Проверенные источники

1. Публичная главная `https://zemipro.co.il/`, навигация на региональные и категорийные хабы, дочерние страницы /master/...
2. Публичные поисковые результаты по `site:zemipro.co.il/master/`, включая /master/lachish/... и /master/center/...
3. Только маршруты и принцип формирования ссылок из приватного PSEO `app.py`, `freez.py`, `index_site/generate_list.py` (без чтения SQL, DB и секретов). По коду текущие активные flow/regions: `master`, `lachish`, `center`; `uslugi` выключен. Эти данные **не** доказывают, какие URL сейчас реально развернуты.
4. `https://zemipro.co.il/sitemap.xml` и `https://zemipro.co.il/robots.txt` были запрошены, но веб-инструмент вернул ошибку доступа к URL. Это **не означает HTTP 404** и не доказывает отсутствие sitemap/robots. Прямая попытка через среду выполнения также не прошла из-за недоступного DNS; живой HTTP-статус не получен.
5. Данные Google Search Console в рамках 00.4 не получены: индексация, показы, клики и внешние ссылки **UNVERIFIED**.

## Правила будущего перевода сайта

- Не переносить HTML, тексты, таблицы и работу Flask. Новый Django проект использует свою структуру каталогов, языки RU/HE/EN и правила конфиденциальности.
- После получения экспортов sitemap и GSC дополнить тот же CSV, без выдуманных URL и показателей.
- По каждой старой странице с подтверждённой SEO-ценностью найти **семантически соответствующую** новую страницу: `KEEP` старого адреса или точечный `301` на готовую новую страницу.
- Страницы без ценности и эквивалента оценивать на `404`/`410`. **Никогда** не делать массовый `301` всего старого раздела на главную.
- Изменения домена, DNS, публикации, CDN, production-redirect rules и отключение PSEO — **только** после согласования этапа 08 и отдельной команды владельца.
- Имеющиеся старые страницы упоминают Telegram и прямую передачу телефона. Эти тексты не должны попасть в новую Django-платформу: Telegram исключён ADR-0001, контакты заказчиков остаются закрытыми.

## Обязательный возврат перед этапом 08

00.4 отложен, но не отменён. **До начала этапа 08** обязательно:

1. Проверить все 21 сохранённый URL.
2. Получить доступные фактические HTTP-статусы.
3. Проверить sitemap и canonical.
4. Проверить доступные данные Google Search Console.
5. Выявить индексируемые страницы и страницы с органическим трафиком.
6. Определить ценность каждого URL.
7. Подготовить индивидуальные решения `KEEP / 301 / 404 / 410` без массового перенаправления на главную.
8. Записать доказательства и решения в `docs/SEO_URL_INVENTORY.csv` и документацию.
9. Только после выполнения проверки разрешить работу над публичным SEO-переключением этапа 08.

Новые целевые URL не придумывать до появления соответствующих Django-страниц. Сейчас не создавать редиректы и не изменять действующий сайт, DNS, Cloudflare, sitemap или robots.

**Гейт:** `DEFERRED / RETURN_BEFORE_STAGE_08`; полнота и поисковые показатели не подтверждены. Начало публичного SEO-переключения этапа 08 запрещено до завершения списка выше.

**Проверки:** адреса CSV уникальны, домен ожидаемый, ни один ряд не помечен как автоматически разрешённый редирект; статическая сверка `PASS`. Django tests, миграции, GSC API, production и SEO-редиректы `NOT_RUN / NOT_TOUCHED`.

## Независимая повторная проверка 2026-11-11

- CSV разобран стандартным `csv.DictReader`: **21 строка, 21 уникальный непустой `old_url`, дубликатов нет**.
- Все строки имеют `page_type`, источник обнаружения, дату наблюдения, статус проверки и evidence; `target_new_url` пуст во всех 21 строках, поэтому документ не выдумывает будущие маршруты.
- Все 21 адрес имеют ожидаемый HTTPS-домен `zemipro.co.il` и остаются `REVIEW / PENDING_GSC_HTTP`.
- Один ограниченный публичный GET главной страницы из Codex Cloud не достиг сайта: Cloud proxy отклонил CONNECT с `403`. Это ограничение среды, а не HTTP-статус ZemiPro; остальные адреса не запрашивались.
- Search Console, sitemap, canonical, индексация и трафик остаются `UNVERIFIED`.

**Перечень для этапа 08:** все 21 строки `docs/SEO_URL_INVENTORY.csv`, сгруппированные как `home`, `region_hub`, `category_hub`, `region_category_hub` и `service_page`. Для каждой после появления соответствующей Django-страницы принять отдельное решение KEEP/301/404/410. До этого `target_new_url` не заполнять.

**Статус:** `DEFERRED / RETURN_BEFORE_STAGE_08`. Потребуются доступ к GSC и/или разрешённая проверка из сети без Cloud proxy; DNS, robots, sitemap и redirects не изменялись.
